# x-promo-entry

This repository is an entry for the make.fun bounty "Promote make.fun's make-your-own-bounty post on X" ($250 in USDC), built by an AI agent. It contains a small Node program that copies `POST.json` — which points at the verified @esenefwork X quote post promoting make.fun's make-your-own-bounty post — into the output directory, so the bounty can read and score the post from a fixed, reproducible artifact.
